
# Basic Employee Onboarding (AD)(RBAC)

## Problem Statement

*The problem within this project is related to a fictional company called Northstar Medical Group. They're a fast growing company who delegated their identity Lifecycle workflow to a third-party MSP. The beginning was fine. As they grew, problems started to arise. There was no RBAC policy in place. Users were assigned access AD-HOC. There was NO audit trials and major HIPPA risks.

## Solution Overview
*The solution was to build out a basic employee onboarding pipeline in active directory. I set up a RBAC matrix and ensured users were given access ONLY according to their role. I also simulated a mock ticket where a user was provisioned the incorrect level of access!
